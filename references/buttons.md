# 按钮与状态

先选语义和层级，再选轮廓。用两个官网的控件角色作参考，并用 OJO 的八态框架覆盖实际反馈。[OJO 组件规范](https://github.com/touchine-ojo/OJO-Design-Skills/blob/3ef911afdc605395a9d74b39eacd0298b70960f9/skills/app-ui-ux-best-practices/references/component-recipe.md#L9-L147)

| 用途 | 选择 | 形态与规则 |
| --- | --- | --- |
| 下载、体验、参与、提交 | 直接到地址使用链接，执行或打开弹层使用按钮 | 横向实色主动作，颜色和字重清楚。按下轻收缩，文字及等待指示保持占位。 |
| 查看发行平台或说明 | 跳转用带地址的链接，展开用按钮 | 延续公司站长框，边线与薄覆层为主。可用 `::after` 做局部淡入，焦点环在外层独立显示。 |
| 预告播放与轮播 | 操作按钮 | 圆形播放和成对上一项、下一项控制。图标圆环有可理解的无障碍名称。对话框和按钮所在页恢复原焦点。 |
| 正文更多、查看详情、返回 | 带真实地址的链接 | 轻量文字、合适的下划线或局部方向标记。正文、导航和选中分类各自保留合适的视觉强度。 |
| 章节切换与筛选 | 导航用链接，页签与筛选用按钮 | 页面内当前位置用 `aria-current="location"`，标签和面板用 `aria-selected`，同组开关筛选用 `aria-pressed`。 |

默认状态用颜色、文字和轮廓区分层级。悬停仅发生于支持指针悬停的设备，效果可为增亮、边框或局部叠层。键盘用高可见度 `:focus-visible`。按压可从 `scale(.98)` 起调并迅速回位。推荐常用触屏动作有约 44px 的最低有效触达区域。减弱动效时保留文本、描边、颜色与焦点。

真正不可用的按钮用 `disabled`。必须保持焦点的忙碌按钮可设置 `aria-busy` 与 `aria-disabled`，并在事件处理器用请求状态防止键盘、鼠标和触摸重复提交。异步成功和错误都给可理解的文本和持续反馈。失败提供重试或修正方式。需要通知辅助技术时给独立状态区。请求、播放、表单或链接各使用适用状态。

当多个控件共同改变预览，或任务需要先决条件、运行和取消时，应用 [控件深度](control-depths.md) 中的联动与流程规则。触感和状态都落在发起动作的控件附近，任务摘要同步呈现跨面板结果。

原生样例中的 [样式](../assets/showcase/showcase.css) 包含 `.action-primary`、`.action-frame`、`.action-icon` 与圆形播放。[脚本](../assets/showcase/showcase.js) 展示本地通行证忙碌、成功、移除、持久化不可用时的降级，以及播放器错误反馈。正式项目按真实接口或平台路径接入，标明影响用户的结果和状态。
