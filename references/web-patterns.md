# 页面实现

[源码证据](source-study.md)保留原站细节与检索标记。本页描述 Tian 的实现选择。可运行参考位于 [折光航线](../assets/showcase/index.html)。

## 场景与内容

- **品牌首页。** 让主视觉、产品段和特色段各自有负责人。宽屏可用媒体面板承载产品比较，或用大图配简短的标题和详情入口。内容型品牌页可以用同一网格铺开时间轴、新闻或招聘入口。全站链接可从品牌、产品名或明确动作进入目标。
- **发布首页。** 读者先看到名称、活动或版本主题与主要操作。海报、可选动视频、遮罩、标题与按钮形成独立层。环境视频只在它承担叙事时加入，用静音、行内播放、封面和暂停路径。预告与用户主动操作绑定。按可见性或按需加载非首屏媒体。
- **混合首页。** 让当前重点发布占首屏，下一章节回答产品或世界的内容问题，再进入更易扫描的编辑式更新。资讯保留日期、分类、标题和能指向完整内容的入口。少量完整日志可用原生展开；文章较多时给详情路由和分页。

## 桌面宽窄面板

1. 将每个媒体面板当作真正的选择控件。用单一索引同时驱动画面宽度、遮罩、当前标记和描述。用户应能点按每个面板，也能用键盘选择。
2. 控件占用的宽度决定画面关系。当前项可分配更多 `flex-grow` 或网格列，次项保留最低可辨认的标题与命中区。悬停和焦点可轻微揭幕，选中才切换内容。把面板宽度、遮罩透明度、详情揭示与主要操作的反馈各自放在对应层上。扫描或派遣按钮维持稳定位置，以本身的忙碌或可用状态反馈结果。
3. 选择立即更新真实参数和条件。过渡期间继续接受有效输入。CSS 可以直接从当前中间宽度向最新选中项过渡；使用时间线时要可中断，防止快速切换后旧过渡覆盖新状态。内容项超过可用空间时，用简洁选择器配独立单画面，留足标题和点击空间。
4. 手机通常将选择控件排成紧凑标签，下一行显示一个完整场景和说明。选中用描边、明暗或原生选中态表达，触摸不需要悬停。通过窄屏截图核对媒体主体和可点区域。减弱动效时直接切到最终宽度、遮罩与详情。

宽窄切换可以承载不同级别的操作。[回波校准](../assets/depth-2/index.html)将频段选中同步到局部图表和读数。[航线调度台](../assets/depth-3/index.html)将选中航线同步到画面、设备要求和派遣资格。

需要更强的场景叙事时，可在宽幅媒体里分开编排镜头、光雾和路线标记。切换时先给画幅空间，再让前景层以不同幅度变化。跨区高亮只标出本次选择新增的要求，完成一轮后回到静态。窄屏沿用单幅场景中的光雾与信息层，减弱动效时保留静态图层、路线标记和必需设备文字。

## 导航、媒体和兼容

| 能力 | 实施建议 | 样例位置 |
| --- | --- | --- |
| 章节与浏览历史 | ID 稳定，`href="#…"` 可直达，吸顶导航用 `scroll-margin`。滚动检测更新当前章，点击或前进后退继续使用浏览器历史。整屏步进仅在项目确有需要时增强，并验证长内容与键盘。 | `section[id]`、`markSection`、`observeSections` |
| 手机菜单 | 以展示按钮和 `aria-expanded` 控制同一导航结构。Esc 和选择后关闭。选中项目后焦点落入目标章节。悬浮操作需给底部内容预留空间。 | `.menu-toggle`、`setMenu` |
| 主视觉 | 先交付封面和真实文本。可用 `picture` 处理艺术指导式裁切，给关键资源声明尺寸，静态封面尽早可用。无需为原站的设备判断机械拆分 URL。 | `.hero-art` 与手机媒体查询 |
| 播放器 | 播放按钮应打开真实可播的媒体。用清楚的名称、焦点管理、Esc 与错误文本。关闭时暂停。 | `.motion-preview`、`filmDialog` |
| 平台操作 | 目的明确时直接链接到所支持的平台，标签与图标一道呈现。需要选择平台时用展开区域或对话框，配置从发行数据读取。 | 按产品提供真实平台与链接 |
| 状态与动效 | 局部控件反馈约 100–180ms 起调。场景可在 240–500ms 之间根据构图试验。减弱动效关掉视差、强制位移及非必要转场，继续保留可见状态和主动播放控制。 | `--fast`、`--scene` 和 `prefers-reduced-motion` |

验收时分别截图首屏、选中第二媒体面板与资讯状态。用手机走一次完整到达路径。测试密集标题、缩放、键盘、快速切换、深链、播放失败、点击回焦和意外缺图。源码判断与新项目按实际运行结论记录。
